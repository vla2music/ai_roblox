# Автообновление кода из GitHub (Rojo)

Чтобы не копировать код в Studio руками каждый раз.

**Как будет работать:** я правлю код и пушу в GitHub → ты делаешь `git pull`
→ Studio обновляется **мгновенно**, пока открыта. Даже нажимать ничего не надо.

Настраивается один раз, минут за 15.

---

## Шаг 1. Скачать проект на макбук

Открой **Терминал** (Cmd+Пробел → набери «Терминал»). Вставь по очереди:

```bash
cd ~/Documents
git clone https://github.com/vla2music/ai_roblox.git
cd ai_roblox
```

Теперь проект лежит в `~/Documents/ai_roblox`.

---

## Шаг 2. Установить Rojo

Rojo — программа, которая связывает папку на диске со Studio.

**Способ 1 — через Homebrew** (если он у тебя есть):
```bash
brew install rojo
```

**Способ 2 — скачать готовый файл:**
1. Открой https://github.com/rojo-rbx/rojo/releases
2. Скачай архив с `macos` в названии
   (`aarch64` для маков на Apple Silicon — M1/M2/M3/M4, `x86_64` для старых на Intel)
3. Распакуй, положи файл `rojo` в `/usr/local/bin`

Проверь, что установилось:
```bash
rojo --version
```
Должна появиться версия. Если «command not found» — значит не установилось, напиши мне.

---

## Шаг 3. Поставить плагин в Studio

```bash
rojo plugin install
```

Одна команда — плагин сам встанет в Roblox Studio.

---

## Шаг 4. Запустить синхронизацию

```bash
cd ~/Documents/ai_roblox
rojo serve
```

В терминале появится что-то вроде `Rojo server listening on port 34872`.

⚠️ **Это окно терминала не закрывай**, пока работаешь — оно и есть «мост».
Закрыл терминал → синхронизация остановилась.

---

## Шаг 5. Подключить Studio

1. Открой Roblox Studio с нашим местом
2. Вкладка **Plugins** сверху → кнопка **Rojo**
3. Нажми **Connect**

⚠️ **ВАЖНО:** перед первым подключением **удали** из Explorer скрипты
`ClubTycoon` и `ClubUI`, которые вставлял руками. Rojo создаст свои,
иначе будет два одинаковых скрипта и игра сломается.

Готово. Теперь любая правка в файлах попадает в Studio сразу.

---

## Как работать дальше

Когда я говорю «залил обновление»:

```bash
cd ~/Documents/ai_roblox
git pull
```

И всё. Если `rojo serve` запущен и Studio подключена — изменения уже в игре.

**Чтобы обновление увидели игроки**, в Studio: **File → Publish to Roblox**.

---

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| `rojo: command not found` | Rojo не установился — вернись к шагу 2 |
| В Studio нет кнопки Rojo | Перезапусти Studio после `rojo plugin install` |
| Connect не подключается | Проверь, что `rojo serve` запущен в терминале |
| Скрипты задвоились | Удали те, что вставлял руками, и переподключись |
