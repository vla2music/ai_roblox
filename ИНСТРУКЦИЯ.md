# Клуб-Тайкун — инструкция по запуску

Игра для Roblox: строишь свой компьютерный клуб, покупаешь ПК, зарабатываешь монеты.

---

## ⚠️ Главное, что нужно знать заранее

**Roblox Studio — программа только для компьютера (Windows или Mac). Версии для телефона не существует.**

Это не наше ограничение, это ограничение самого Roblox. С телефона можно
*играть* в Roblox, но нельзя *делать* игры и нельзя их публиковать.

Хорошая новость: компьютер нужен **не постоянно**, а примерно на **1 час один раз**.
Всё остальное — код, идеи, баланс, новые фишки — делаем здесь, с телефона.

**Сколько времени за компьютером нужно:**

| Шаг | Сколько занимает | Как часто |
|---|---|---|
| Установить Roblox Studio | 15 минут | Один раз |
| Вставить код и опубликовать | 20 минут | Один раз |
| Обновить игру после правок | 5 минут | Когда захотим что-то добавить |

Подойдёт любой: домашний, родительский, школьный, у друга.

---

## ✅ Про сервер — хорошая новость

**Свой сервер не нужен вообще. Ни на телефоне, ни на компьютере. Совсем.**

Roblox всё делает сам и бесплатно:

- **Серверы** — Roblox запускает их по всему миру, когда игроки заходят в твою игру
- **Сохранение прогресса** — встроенная система DataStore, уже подключена в нашем коде
- **Платежи** — Roblox сам принимает деньги за геймпассы
- **Обновления** — нажал «Publish», и у всех игроков сразу новая версия

Ты платишь **0 рублей** за хостинг. Навсегда.

---

## Шаг 1. Аккаунт Roblox

1. Зайди на **roblox.com** и зарегистрируйся (или войди в существующий аккаунт)
2. Подтверди почту — без этого нельзя публиковать игры

> Если Назару нет 13 лет — часть функций ограничена. В 14–15 всё доступно.

---

## Шаг 2. Установить Roblox Studio

1. На компьютере открой **create.roblox.com**
2. Нажми большую кнопку **Start Creating** → скачается установщик
3. Запусти его, дождись установки (5–10 минут)
4. Открой Studio и войди под своим аккаунтом

---

## Шаг 3. Создать место для игры

1. В Studio нажми **New** → выбери шаблон **Baseplate** (простая серая площадка)
2. Открылось окно с серым полом — это и есть наш будущий клуб

---

## Шаг 4. Вставить серверный код

Справа вверху есть панель **Explorer** (если её нет: меню **View → Explorer**).

1. В Explorer найди строку **ServerScriptService**
2. Наведи на неё мышкой → нажми **➕** → выбери **Script**
3. Появился новый скрипт и открылось окно с текстом. **Удали оттуда всё** (Ctrl+A, затем Delete)
4. Открой файл `src/ServerScriptService/ClubTycoon.server.lua` из нашего репозитория,
   скопируй **весь** текст и вставь в Studio (Ctrl+V)
5. Переименуй скрипт: правой кнопкой по нему в Explorer → **Rename** → напиши `ClubTycoon`

---

## Шаг 5. Вставить код интерфейса

1. В Explorer найди **StarterPlayer**, нажми на стрелочку слева от неё — раскроется
2. Внутри будет **StarterPlayerScripts**
3. Наведи на неё → **➕** → выбери **LocalScript** (именно LocalScript, не Script!)
4. Удали весь текст внутри
5. Скопируй содержимое файла `src/StarterPlayer/StarterPlayerScripts/ClubUI.client.lua`
   и вставь
6. Переименуй в `ClubUI`

---

## Шаг 6. Включить сохранение прогресса

Без этой галочки игроки будут терять всё при выходе.

1. В Studio: меню **File → Game Settings**
2. Слева выбери вкладку **Security**
3. Включи переключатель **Enable Studio Access to API Services**
4. Нажми **Save**

---

## Шаг 7. Проверить, что работает

1. Нажми большую кнопку **Play** (▶) сверху
2. Ты появишься на зелёной площадке своего участка
3. Подойди к красной кнопке **«Ресепшн»** и наступи на неё — она бесплатная
4. Появится ресепшн, в сейфе начнут капать монеты
5. Подойди к жёлтому **СЕЙФУ** — монеты перейдут тебе
6. Теперь доступна кнопка «Игровой ПК №1» за 25 монет

Если всё так — игра работает! 🎉

> **Если что-то пошло не так:** внизу Studio есть окно **Output** (меню **View → Output**).
> Там будут красные строчки с ошибками — скинь их мне, и я исправлю.

---

## Шаг 8. Опубликовать игру

1. Меню **File → Publish to Roblox**
2. Придумай название — например, **«Cyber Club Tycoon»**
3. Напиши короткое описание
4. Нажми **Create**

Игра создана, но пока видишь её только ты. Чтобы её могли найти другие:

1. Зайди на **create.roblox.com** → раздел **Creations**
2. Найди свою игру → нажми на **⋯** → **Configure**
3. Вкладка **Permissions** (или **Basic Settings**) → поставь **Public**
4. Готово — теперь игру может найти и запустить кто угодно 🌍

---

## Шаг 9. Заработок (делается позже, когда игра готова)

1. На странице игры → **Monetization** → **Passes** → **Create a Pass**
2. Назови его, например, **«x2 Монеты»**, поставь цену 49 Robux
3. Скопируй **ID геймпасса** из адресной строки
4. В коде найди строку `DOUBLE_CASH_GAMEPASS = 0` и впиши туда этот номер
5. Опубликуй игру заново (**File → Publish to Roblox** → выбрать ту же игру)

Теперь у купивших геймпасс доход будет вдвое больше.

## Как менять игру дальше

Почти всё настраивается в **одном месте** — в таблице `ITEMS` в начале серверного скрипта.

**Изменить цену или доход:**
```lua
{ id="pc1", name="Игровой ПК №1", cost=25, income=2, ... }
                                  ↑        ↑
                              цена    монет в секунду
```

**Добавить новую покупку** — просто добавь строчку в конец таблицы:
```lua
{ id="bar", name="Барная стойка", cost=70000, income=400, needs="neon",
  pos=Vector3.new(20, 0, 20), kind="box", size=Vector3.new(14,5,4),
  color=Color3.fromRGB(180,60,60) },
```

- `id` — уникальное имя латиницей
- `needs` — что нужно купить перед этим
- `pos` — где стоит (X — влево/вправо, Y — высота, Z — вперёд/назад)
- `kind` — внешний вид: `desk`, `box`, `zone`, `sign`, `walls`

Больше ничего править не нужно — кнопка, подпись и логика создадутся сами.
