# 🖥️ Клуб-Тайкун

Игра для Roblox: строишь свой компьютерный клуб, покупаешь игровые ПК,
кресла, автомат с едой и турнирную сцену — зарабатываешь монеты.

**Автор: Назар**

## Что внутри

```
src/
├── ServerScriptService/
│   └── ClubTycoon.server.lua      — вся логика: участки, покупки, деньги, сохранения
└── StarterPlayer/
    └── StarterPlayerScripts/
        └── ClubUI.client.lua      — интерфейс игрока
```

Весь мир строится прямо из кода — вручную в редакторе лепить ничего не нужно.

## Как запустить

Смотри **[ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md)** — там всё по шагам.

## Как это работает

- Заходит игрок → ему выдаётся свободный участок
- На участке красные кнопки. Наступил → купил → объект вырастает из земли
- Каждая покупка приносит монеты в секунду, они копятся в **сейфе**
- Подошёл к сейфу → забрал монеты → купил следующую покупку
- Прогресс сохраняется автоматически (Roblox DataStore)

## Настройка

Всё, что нужно менять, лежит в таблицах `CONFIG` и `ITEMS`
в начале файла `ClubTycoon.server.lua`.
