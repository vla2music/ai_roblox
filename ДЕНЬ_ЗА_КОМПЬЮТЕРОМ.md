# 🖥️ План на день за компьютером

Распечатай или открой на телефоне рядом. Весь день — примерно **1 час 20 минут**.

---

## Перед тем как сесть (проверить заранее!)

- [ ] Компьютер — **Windows или Mac** (не Linux, не планшет)
- [ ] Есть права **устанавливать программы** (если компьютер рабочий/школьный — может не дать)
- [ ] Интернет нормальный (Studio весит ~500 МБ)
- [ ] Знаем **логин и пароль** от аккаунта Roblox
- [ ] Почта на аккаунте **подтверждена** (без этого не опубликовать игру)

> Если хоть один пункт не сходится — напиши мне заранее, придумаем обход.

---

## Часть 1. Установка — 20 минут

- [ ] Открыть **create.roblox.com**
- [ ] Нажать **Start Creating** → скачается установщик
- [ ] Установить, открыть Studio, войти в аккаунт
- [ ] **New** → шаблон **Baseplate**

✅ Видим серую площадку — идём дальше.

---

## Часть 2. Вставляем код — 20 минут

**Серверный скрипт:**
- [ ] Панель **Explorer** справа (если нет: **View → Explorer**)
- [ ] **ServerScriptService** → ➕ → **Script**
- [ ] Стереть весь текст внутри (Ctrl+A, Delete)
- [ ] Вставить код из `src/ServerScriptService/ClubTycoon.server.lua`
- [ ] Переименовать скрипт в `ClubTycoon`

**Интерфейс:**
- [ ] **StarterPlayer** → раскрыть → **StarterPlayerScripts**
- [ ] ➕ → **LocalScript** ⚠️ (именно LocalScript, а не Script!)
- [ ] Стереть текст, вставить код из `ClubUI.client.lua`
- [ ] Переименовать в `ClubUI`

**Включить сохранения:**
- [ ] **File → Game Settings → Security**
- [ ] Включить **Enable Studio Access to API Services** → **Save**

---

## Часть 3. Первый запуск — 15 минут

- [ ] Нажать **Play** (▶)
- [ ] Появились на зелёной площадке?
- [ ] Наступить на красную кнопку **«Ресепшн»** (бесплатно)
- [ ] Ресепшн вырос из земли?
- [ ] В жёлтом **СЕЙФЕ** побежали цифры?
- [ ] Подойти к сейфу — монеты перешли наверх экрана?
- [ ] Появилась кнопка «Игровой ПК №1» за 25 монет?
- [ ] Купить ПК — появился стол с монитором?

🎉 **Если все галочки — игра работает!**

**Если что-то не так:** открыть **View → Output**, сфотографировать красные строчки
и прислать мне. Починю.

---

## Часть 4. Публикация — 10 минут

- [ ] **File → Publish to Roblox**
- [ ] Название игры: `______________________` (придумать заранее!)
- [ ] Описание: пара предложений
- [ ] **Create**
- [ ] Зайти на **create.roblox.com → Creations → своя игра → ⋯ → Configure**
- [ ] Вкладка **Permissions** → поставить **Public**

🌍 Игра в интернете! Ссылку можно кидать друзьям.

---

## Часть 5. Проверка вдвоём — 15 минут

- [ ] Зайти в игру **с телефона** (через обычное приложение Roblox)
- [ ] Проверить: прогресс сохранился с прошлого раза?
- [ ] Позвать друга зайти одновременно — у каждого свой участок?
- [ ] Поиграть 10 минут и записать:
  - Что понравилось: `_______________________`
  - Где стало скучно: `_______________________`
  - Что бесит: `_______________________`

---

## После — возвращаемся ко мне

Присылаешь ответы из части 5, и я сразу правлю баланс и добавляю то,
что реально держит игроков: **ребёрт**, **питомцев**, **ежедневные награды**.

---

## ⚠️ Три главные ошибки новичков

1. **Вставить интерфейс как Script вместо LocalScript** — тогда панели сверху не будет
2. **Забыть включить API Services** — прогресс не сохранится
3. **Забыть поставить Public** — игру будешь видеть только ты
