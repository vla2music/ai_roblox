# Магнат киберклуба (Cyber Club Tycoon) — Roblox-игра Назара

Пользователь (VLA2music, музыкант, отец Назара) пишет по-русски, новичок в Roblox.
Отвечать по-русски, просто, без жаргона. Цель игры — заработок (рынок США), честно, без давления на детей.

## Как работаем
- Код в `src/`, синхронизация в Studio через **Rojo** (`rojo serve` из этой папки, порт 34872).
  Проверь: `pgrep -fl "rojo serve"`; если нет — запусти в фоне. В Studio плагин Rojo → Connect (делает пользователь).
- **Roblox Studio MCP** подключён (`Roblox_Studio`): сначала `list_roblox_studios` → `studio_id`.
  Проверка: `start_stop_play` → `execute_luau` (Server/Client) → `get_console_output` → `screen_capture`.
  Если в Play код старый («NOT SYNCED») — Rojo отключился, попросить Connect.
- Мир строится кодом при запуске (~30 сек). После каждой правки — коммит в git.
- В Studio геймпассы отключены (`STUDIO_IGNORE_PASSES`), сброс прогресса игрока: `player:SetAttribute("DevReset", true)` на сервере.
- Модели из магазина лежат ВНУТРИ места (не в файлах): `ServerStorage/Шаблоны` (pc, chair, reception, vending, ac, graffiti1-5, cruise, yacht), `ReplicatedFirst/КлиентШаблоны` (drone, Машины). Пользователь должен сохранять место ⌘S.
- ⚠️ Нельзя загружать реальные фото/видео детей (было предупреждение модерации Roblox).

## Файлы
- `ServerScriptService/ClubTycoon.server.lua` — вся логика клуба: ITEMS (группы разворачиваются в покупки по одной), экономика (C0=12, рост 1.22, окупаемость 30+6·i ≈ 25 мин), банкомат/монеты, кнопки, ребёрт (+0.5x), энергия/лимонады, мини-игры (сервер-проверка), геймпассы, ProcessReceipt, NPC (посетители, продавец, уборщик, кот, админ), музыка, салют.
- `World.server.lua` — газон, горы (не за клубами), водопады, деревья, облака. Ставит `workspace.WorldReady`.
- `City.server.lua` — лента-петля, киберквартал, улицы, трасса, парковки, киоски лимонадов (дешевле x3), колесо, горки, тоннели, сундук-клад, табло рекордов, пешеходы.
- `Sea.server.lua` — море (заливается кусками 200x200 дважды), луна, набережная, лайнер, яхты, смотровая башня с лестницей и парашютом. Звуки чаек/толпы: `SOUND_GULLS`, `SOUND_CROWD` — пустые, ждут ID.
- `Rooftops.server.lua` — лифты на крыши всех небоскрёбов (имя «Небоскрёб»), парашюты на крышах, сундуки на 8 крышах и палубах (атрибут модели `Ship`), перерыв 10 мин.
- `Paraglider.server.lua` + `Paraglider.client.lua` — параплан с самого высокого дома, 14 колец, сервер проверяет кольца. Тест: `ServerStorage.DevStartGlider:Fire(player)`.
- `Billboards.server.lua` + `NazarTok.client.lua` — экраны NazarTok (анимированные «ролики» с подсказками, не настоящее видео), рекламные баннеры, граффити с подсказками.
- Входная дверь клуба — в `builders.outer` (ClubTycoon): открывает только хозяин.
- ⚠️ Имена атрибутов — только латиница; к объектам с русскими именами обращаться через `FindFirstChild("…")`, не через точку.
- `ReplicatedStorage/ClubShared.lua` — геймпассы, пачки монет, уровни ПК, награды, лимонады.
- Клиент: `ClubUI` (панель, ребёрт), `Menus` (магазин, ПК, награды, друзья, энергия, бусты, луч к цели), `MiniGames`, `Rides` (колесо, горки, лента), `Life` (экраны, машины со звуком, дрон), `Sky` (самолёты, шары), `Birds` (птицы, чайки), `Parachute`.
